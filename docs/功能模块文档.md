# Sesame-TK 功能模块文档

> 本文档介绍芝麻粒-TK 的各个功能模块。所有功能模块均作为 `Model` 子类注册，通过 [ModelOrder](file:///e:/workspace/AndroidStudioProjects/Sesame-TK/app/src/main/java/fansirsqi/xposed/sesame/model/ModelOrder.kt) 的 `array` 声明加载顺序。任务类统一继承 `ModelTask`，在支付宝内以 RPC 方式执行各类业务操作。

## 2. 基础模块（BaseModel）

全局开关与通用运行配置，是模块的心脏。核心配置项包括：

- **启用模块**：模块总开关（默认开启）。
- **手动触发自动安排下次执行**：手动执行任务后是否自动重新调度。
- **执行间隔时间**：轮询间隔，决定两次主任务执行的间隔。
- **轮数**：每轮主任务执行时各任务的执行轮数。
- **模块休眠时间范围**：指定时间段内暂停所有任务。
- **定时执行的时间点列表**：可指定多个具体时间点执行任务。
- **能量收集的时间范围**：「只收能量时间」，该时段内非森林任务会被 `check()` 拦截（见 `TaskCommon`）。
- **超时是否重启 / 异常等待时间 / 异常通知开关 / 异常次数阈值**：异常兜底策略。
- **是否启用新接口（newRpc）**：切换 `NewRpcBridge` / `OldRpcBridge`。
- **是否启用 WebView Hook**：WebView 调试。
- **调试模式 / 抓包 / Hook 数据转发（仅 DEBUG）**：用于开发调试。
- **电池权限申请、记录日志、显示气泡、状态栏禁删、只显示中文并设置时区、气泡偏移/前缀**：运行表现。
- **启用内置解锁、锁屏类型、锁屏密码、解锁超时/重试次数**：配合解锁服务。
- **任务最大并发数、任务默认超时、任务超时白名单**：`CoroutineTaskRunner` 的并发与超时控制。

## 3. 蚂蚁森林（AntForest）

核心功能模块，继承 `ModelTask` 并实现 `EnergyCollectCallback`，支持「蹲点收取」模式。职责由多个协作者分解（`ForestEnergyCollector`、`ForestShieldManager`、`ForestItemManager`、`ForestStatistics`、`EnergyWaitingManager` 等）。

主要功能点：

### 3.1 能量收取
- **收集能量**（`collectEnergy`）：主开关。
- **批量收取**（`batchRobEnergy`）：一次性批量收取好友能量。
- **收自己能量方式**（`collectSelfEnergyType`）：所有 / 大于阈值 / 小于阈值，配合 `collectSelfEnergyThreshold`。
- **提前时间 / 尝试次数 / 重试间隔**：`advanceTime`、`tryCount`、`retryInterval`，蹲点精度控制。
- **平衡网络延迟**（`balanceNetworkDelay`）：根据请求耗时微调提前量。
- **不收取能量用户列表**（`dontCollectList`）、**收取浇水金球**（`collectWateringBubble`）。
- **1.1 倍能量卡 / 炸弹能量**：`robExpandCardLimt`、`collectBombEnergyLimit`。

### 3.2 能量挑战与游戏
- **PK能量**（`pkEnergy`）：森林 PK。
- **1V1 能量挑战**（`energyPvpChallenge`）：由 `EnergyPvpChallengePolicy` 决策。
- **能量雨**（`energyRain`）：定时执行，`energyRainTime`、`energyRainChance`。
- **6秒拼手速**（`whackMoleMode` 兼容/激进）：`WhackMole`，配置局数 `whackMoleGames`、次数 `whackMoleMoleCount`、时间 `whackMoleTime`。
- **森林抽抽乐**（`forestChouChouLe`）：`ForestChouChouLe`。

### 3.3 道具管理（ForestItemManager）
- **双击卡**（`doubleCard`）：类型 + 使用时间列表 + 次数限制，支持「永动机」（`doubleCardConstant`）。
- **隐身卡**（`stealthCard`）、**保护罩**（`shieldCard`，`ForestShieldManager` 管理）、**加速卡**（`bubbleBoostCard`）。
- **收集道具**（`collectProp`）、**显示背包**（`showBagList`）。
- **收集道具的时间间隔控制**：`queryInterval`、`collectInterval`、`doubleCollectInterval`。

### 3.4 互助与能量
- **帮好友收能量**（`helpFriendCollectType`、`helpFriendCollectList`）。
- **小号/备用号**（`alternativeAccountList`）：备用账号轮换收取。
- **回能量**（`returnWater33 / returnWater18 / returnWater10`）：回送指定能量。
- **浇水好友**（`waterFriendList`、`waterFriendCount`）、**提醒好友**（`notifyFriend`）。
- **赠送道具**（`giveProp`）、**给谁**（`whoYouWantToGiveTo`）。

### 3.5 活力值与兑换
- **活力值兑换**（`vitalityExchange`）：`Vitality`（`task/antForest/Vitality.kt`），限时秒杀 `vitalitySecKill`。
- **活力值兑换列表**（`vitalityExchangeList`）。

### 3.6 特权与其他
- **青春特权**（`youthPrivilege`、`dailyCheckIn`、`studentSignInRedEnvelope`）。
- **医疗健康**（`medicalHealth`）：`Healthcare`。
- **绿色行动**（`ecoLift`）：`GreenLife` / `EcoLife`，定时 `ecoLiftTime`。
- **7天环保打卡 / 7天签到**：`ecodailyTask`、`gift7thSign`。
- **森林市场**（`forestMarket`）、**合成动物碎片**（`combineAnimalPiece`）、**消耗道具**（`consumeAnimalProp`）。
- **领取森林任务奖励**（`receiveForestTaskAward`）、**守护任务**（`Privilege` / `Vitality`）。

### 3.7 蹲点等待（EnergyWaitingManager）
核心守护机制，支持：
- 多好友能量成熟时间排队等待（`EnergyWaitingManager` / `EnergyWaitingPersistence`）。
- 账号切换/服务销毁时保存快照并在重建后恢复（V3 收口方案）。
- 配合 `SmartSchedulerManager` 保活，确保到点准时收取。

## 4. 蚂蚁庄园（AntFarm）

庄园自动喂养与经营：

- **喂养**：`FarmFeedManager` 自动投喂小鸡。
- **产出收取**：收取鸡蛋、五谷等。
- **庄园任务**：饲料任务、捣乱/蹭饭管理。
- **商店**：`FarmShopManager` 兑换道具。
- **捐赠**：`FarmDonateManager` 好友捐赠。
- **道具管理**：`FarmItemManager`。
- **家族**：`AntFarmFamily` 家族互助。
- **抽抽乐**：`ChouChouLe`。
- **每日任务**：`DadaDailyRpcCall` 等 RPC 封装。

## 17. 手动任务（customTasks）

- **CustomTask**：庄园子任务枚举（`task/customTasks/CustomTask.kt`），定义森林打地鼠、能量雨、遣返小鸡、庄园游戏改分、庄园抽抽乐、庄园特殊美食、庄园道具、触发验证码等手动可触发的子任务类型。
- **ManualTask**：手动庄园任务流，支持手动触发且与自动任务互斥（`ManualTask.isManualRunning` 会中断自动调度）。
- **ManualTaskModel**：手动任务配置模型，UI 通过 `ManualTaskActivity` 配置与触发。

## 18. 支撑性模块

以下模块不直接对应某个支付宝业务，但为任务执行提供关键能力：

- **TaskBlacklist / defaultBlacklist**：任务黑名单，屏蔽某些任务/用户。
- **EnergyWaitingManager / EnergyWaitingPersistence**：森林蹲点等待与持久化（蹲点引擎已下沉为会话级 `WaitingAccountSession`，详见 [任务执行流程分析.md](file:///e:/workspace/AndroidStudioProjects/Sesame-TK/docs/任务执行流程分析.md) §3）。
- **UserEnergyPatternManager**：用户能量成熟规律学习，辅助蹲点。
- **ForestStatistics**：森林收取统计。
- **DeviceStateChecker / NetworkUtils**：设备状态与网络检测。
- **DirectoryWatcher**：配置文件目录监听（热更新）。
- **TaskTimeChecker / GameIntervalCalculator**：任务时间与游戏间隔计算。
- **hook/view/ 视图模拟**：`PageMonitor` 页面监控、`ViewHierarchyAnalyzer` 视图层级分析、`WebViewAccessibilityFinder` WebView 无障碍查找、`XpathParser` XPath 解析、`ViewImage` 视图截图等，为验证码处理与 UI 自动化提供视图层能力。
- **hook/compat/ 双后端兼容层**：`Hooker` 抽象 + `lsp102/Lsp102Hooker`（现代 LSPosed）+ `xp82/Xp82Hooker`（传统 Xposed），统一 Hook API 差异。
- **hook/internal/ 内部助手**：`SecurityBodyHelper`（SecurityBody 加载）、`AlipayMiniMarkHelper`（小程序标记）、`LocationHelper`（定位）、`AuthCodeHelper`（授权码），在 `ApplicationHook.hookApplicationAttach` 中初始化。

## 19. 辅助服务能力

- **内置解锁**（`service/unlock/`）：`UnlockManager` + `UnlockAccessibilityService`，解锁期间上滑 + 点按锁屏数字键。
- **Shell 能力**（`service/`）：`ShellManager` 支持 Root / Shizuku / 无 三种类型（见 `ShellType`），`SafeRootShell`（`service/patch/PatchedRootShell.kt`）提供增强 Root 命令执行。`ShizukuChecker` 检测 Shizuku 授权状态。
- **RPC 调试**（`hook/rpc/debug/`）：`DebugRpc` / `DebugRpcCall` 抓包与转发。
- **验证码处理**（`hook/captcha/` + `hook/view/`）：`CaptchaHook` 拦截验证码弹窗，`Captcha1/2Handler` 分类处理，`RpcPauseGate` 挂起等待；滑块识别由 `hook/view/SliderTFLite`（LiteRT 模型）完成，`hook/view/MotionEventSimulator` / `SystemInputSwiper` 负责模拟手势滑动。
- **HTTP 调试服务器**（`hook/server/`）：`ModuleHttpServer`（NanoHTTPD）提供 `/debugHandler`、`/getAlipayMiniMark`、`/getAuthCode` 接口。

## 20. 功能模块使用建议

1. 各模块在 UI 中独立开关，按需开启，避免不必要的高频请求触发风控。
2. 森林模块功能最重，涉及大量道具/挑战/蹲点逻辑，建议按需开启子项。
3. 「只收能量时间」期间其他任务会被自动拦截，注意与「模块休眠时间」配合避免冲突。
4. 多账号切换时，蹲点任务会随账号切换保存/恢复快照，确保旧账号任务不污染新账号。
